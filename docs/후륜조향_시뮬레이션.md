# 전륜 구동·후륜 조향 실행

기존 실행 메뉴를 그대로 사용한다. GUI·전체 실행·맵 1–8은 공통 설정으로 차량을 생성한다.

```bash
./scripts/run_gui.sh
# 또는
./scripts/run_terrain_navigation.sh
```

| 설정 / 코드 | 역할 |
|---|---|
| `src/nomad_bringup/config/vehicle.yaml` | 현재 차량: 전륜 구동·후륜 조향, 기하·한계·기준축 |
| `src/nomad_vehicle_model/nomad_vehicle_model/` | 공통 원호 적분·좌우 조향 믹서·실측각 역산 |
| `src/nomad_gazebo/scripts/generate_vehicle.py` | 같은 입력으로 SDF·URDF·메타데이터 생성 |
| `src/nomad_gazebo/scripts/rear_steering_mixer.py` | Gazebo 관절 출력, 피드백·시각·명령 만료 검사 |
| `src/nomad_control/nomad_control/controller.py` | 명령 계약 검사·실측 속도/뒤 관절 피드백 |
| `src/nomad_path_planning/nomad_path_planning/{gpp,lpp}/` | 앞축 기준 경로 예측·추종, 기존 알고리즘 선택 유지 |

데이터 흐름: Planning `DriveCommand` → Control `/cmd_vel` → watchdog → 관절 믹서 → 앞바퀴 속도 2개·뒤 조향각 2개.
수동 조종도 같은 출력 경로를 사용한다. 믹서는 한 입력 모드만 구독한다.

속도는 비조향 앞축의 **m/s**, 조향은 **등가 자전거 각도 rad**다. 전진 좌회전 양수이며 실제 뒤 조향은 음수다. 후진은 속도 부호로만 yaw가 바뀐다.
base_link 위치·새 전방 +X는 유지한다. 앞축이 차체 기준보다 0.36m 앞에 있어 `reference_offset=-0.36m`다.
GPP·RPP·Rollout·관측 안전검사·복구 예측은 같은 기준을 사용한다. 실행 외곽은 바퀴 모서리를 포함한 반길이0.52m·반폭0.42m다.

현재 한계는 속도0.5m/s·등가 조향0.4rad, 물리 안쪽 관절0.55rad다. 축간0.72m·윤거0.60m·반경0.15m·질량34.6kg는 임시 블록 모델이며 실차 측정값이 아니다.
기하를 바꿀 때 공통 차량 YAML과 외곽·제동 한계도 함께 확인한다. 모듈별 YAML로 기하를 따로 덮어쓰면 실행을 거부한다.
카메라 K/D, optical 축, IMU·GNSS lever arm은 조향 변경만으로 임의 반전하지 않는다. 실제 센서 재장착 시 별도로 보정한다.

## 단독 물리 시험

```bash
./scripts/run_rear_steering_sim.sh                  # 격리 domain152, 평지
./scripts/run_rear_steering_sim.sh headless:=false  # Gazebo 창 포함
```

단독 시험 입력은 `/nomad/rear_steer/drive_command`(DriveCommand), 상태는 `/nomad/rear_steer/status`(JSON)다. 전체 실행의 입력 모드는 watchdog 뒤 Twist이며 두 입력을 동시에 사용하지 않는다.
명령 stamp는 ROS 시각, frame은 base_link, 유효기간은 0초 초과·0.5초 이하. wall 만료0.35초, 실제 관절/속도 피드백 소실·시각 역행 시 정지한다.
일시정지 중 명령도 만료된다. 시각 역행 후에는 재실행한다. 관절 믹서 또는 ROS bridge 종료 시 시뮬레이션 전체를 종료해 구동 명령이 남지 않게 한다.

## 이전 차량 재현

```bash
./scripts/run_terrain_navigation.sh vehicle_file:="$PWD/src/nomad_bringup/config/vehicle_legacy.yaml"
```

이 설정은 이전 후륜 구동·전륜 조향 Ackermann 플러그인을 생성하고 플래닝/Control도 같은 기준으로 바꾼다. 기존 맵 지형과 과거 실험 자료는 보존한다.

실차는 VESC 1개·기계식 차동·서보 1개이며 시뮬레이션의 네 관절 출력을 그대로 네 액추에이터에 보내지 않는다. 실제 서보 중립/방향·m/s↔ERPM·제동과 센서 TF 보정은 별도 단계다.
