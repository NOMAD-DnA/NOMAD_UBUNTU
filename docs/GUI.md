# 실행 GUI

```bash
./scripts/run_gui.sh  # 실행 메뉴 열기
```

기능 선택 → 설정 확인 → 실행. GUI에서 실행한 프로세스만 선택/전체 종료한다.
전체 주행을 실행하면 초기 정렬 조종 창도 함께 열린다. 2–3 m 이동 → 위치 정렬 완료 시 자동 정지·조종 창 종료 → 지도 READY·실제 정지 3초 확인 → RViz 목표 지정. 세부 설정의 초기 정렬 조종 창 옵션으로 켜고 끌 수 있다.

## 설정

짧은 이름과 단위를 표시한다. 마우스를 올리면 간단한 설명, 클릭하면 같은 설명이 아래에 고정된다.
오른쪽 아래 `자세한 설명`을 켜면 클릭한 옵션의 의미·사용처·변경 영향을 확인한다.
맵·센서를 바꾸면 실행용 센서 모델·VIO 보정·TF·융합 설정을 함께 만든다. 원본 config는 유지한다.
이미 실행 중인 노드에는 변경이 적용되지 않는다.

클래스 목록 입력: `[8]`, `[8, 3]`, `[3, 4]`, `[]`. 복수 목록은 형식 예시이며 통행 권장은 아니다.

## 시각화

| 파트 | 표시 옵션 |
|---|---|
| 시뮬레이션 | Gazebo 창, GPS 궤적 |
| 의미분할 | 분할 영상 창 |
| 지도 | RViz, 경사·클래스·주행가능성 전용 창 |
| 위치추정 | RViz 정렬된 VIO 포즈·융합 궤적 — 초기 정렬 후 표시 |
| 플래닝 | RViz GPP·LPP 경로 |
| 제어 | RViz 차량 위치·자세 |

실시간 실행 로그 위에서 **노드·로그 수준·검색어**를 선택한다. 화면 필터와 관계없이 전체 메시지가 저장된다.

## 저장 로그 분석

`로그 저장` → 기록 이름 입력. 수치 CSV·지도 스냅샷은 실행 중 자동으로 모아 함께 저장한다.
실행 콘솔·실행 명령·설정·자동 수집한 수치 파일과 요약 PNG를 보관한다. ROS 토픽·영상·rosbag을 녹화하지 않는다.
기본 저장 위치: `log/gui_sessions/`. `NOMAD_LOG_DIR`로 변경 가능.

`로그 보기` → 이름·시간으로 기록 선택 → 필요한 파일·수치만 체크.
3D 궤적, 시간 그래프, 분포, 지도·이미지, 실행 텍스트·설정을 볼 수 있다.
재생/일시 정지·배속·슬라이더로 저장된 수치 기록을 살펴보고 `현재 그림 저장`으로 내보낸다.
기존 결과는 `결과 파일 열기`로 바로 확인할 수도 있다.

- 수치: TUM, CSV, JSON, JSONL. 헤더 없는 수치 파일은 앞 네 열을 `시간 x y z`로 해석한다.
- 지도·사진: NPZ의 2D 배열, PNG/JPEG. 지도 스냅샷은 저장된 한 시점이며 이력 애니메이션을 만들지 않는다.
- 3D 비교: 원본 좌표로 표시. 필요하면 기준 파일을 선택하고 `SE(3) 정렬`을 켠다. 스케일은 유지한다.
- 시간 단위 자동 추정이 맞지 않으면 s/ms/us/ns를 직접 선택한다. 좌표·기준점·위치 단위는 파일끼리 맞아야 한다.
- 위치 수치가 없는 텍스트 로그는 텍스트로 확인한다. 없는 데이터를 만들어서 궤적으로 표시하지 않는다.

메뉴 추가: `src/nomad_bringup/gui/menu.json`. 표시 설명: `option_help.py`.
