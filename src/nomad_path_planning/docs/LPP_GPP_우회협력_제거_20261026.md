## 실행과 복구
기존 GUI/CLI 실행 방식은 동일하다. 새 터미널에서 기존 명령을 사용한다.
이미 실행 중이던 노드는 소스 변경만으로 바뀌지 않으며 다음 실행부터 반영된다.
사용자 정의 topics.yaml에 planning.lpp_progress를 추가했던 경우 해당 키를 제거해야 한다.

소스는 Git 미커밋 변경으로 남겼고 commit/push하지 않았다.
선택적 제거 패치는 다음에 보관했다.
`/home/user/문서/ChatGPT/자율주행/.remove_lpp_cooperation_20261026/remove.patch`
복구가 필요한 경우 이후 변경과 충돌 여부를 먼저 확인하고 이 패치만 역적용한 뒤 재빌드한다.
전체 reset을 사용하면 다른 변경까지 잃을 수 있으므로 사용하지 않는다.
```bash
git apply --reverse --check /home/user/문서/ChatGPT/자율주행/.remove_lpp_cooperation_20261026/remove.patch
git apply --reverse /home/user/문서/ChatGPT/자율주행/.remove_lpp_cooperation_20261026/remove.patch
```
이 문서는 제거 이력으로 남으며 역적용 시 자동 삭제되지 않는다.
생성 산출물 백업은 같은 디렉터리의 generated_backup/{build,install}에 보존했다.
백업에는 상대 symlink가 있으므로 직접 실행하지 말고 원래 패키지 경로로 복원하거나 재빌드한다.
