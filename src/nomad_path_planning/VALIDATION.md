## ROS 노드 전체 연결 검증

`scripts/verify_ros.py`는 빈 별도 domain에서 실제 네 계획 노드를 launch하고
가상 `/clock`, `/odom`, `/scan`, TF를 발행한다. 센서 QoS는 best-effort로 테스트한다.
제어 출력은 `/nomad/test/cmd_vel`로 remap한다. Gazebo 물리 시험은 아니다.

- open: 목표 전에는 0, 목표 뒤 전진, 목표 도착 후 정지, 모든 경로 frame은 `odom`.
- reverse: 전방 벽으로 전진 후보가 막히면 음의 속도가 발행되고 가상 차량이 후진.
- blocked: 전후방이 막힌 동안 이동 명령 0 유지.
- 모든 시나리오에서 LiDAR 발행 중단 후 센서 health=false 및 속도 0 확인.

반복 검증 중 GPP는 목표를 받았지만 제어기는 첫 목표를 놓쳐 대기하는 시작 순서
문제를 발견했다. 내부 목표/전역 경로의 publisher와 subscriber를 transient-local로
통일해 마지막 값을 전달하도록 수정했다. 제어 명령 타이머는 NOMAD의 wall-clock
watchdog에 맞춰 10Hz steady clock으로 이식했고, 시계 정지 시에는 0을 발행한다.

최종 코드 재검증 결과: open **PASS** (가상 XY 이동 2.659m), reverse **PASS**
(가상 X 변위 -0.210m), blocked **PASS** (변위 0m). 세 경우 모두 센서 단절 정지 통과.
