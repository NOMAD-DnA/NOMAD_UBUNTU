페이지 열기·새로고침·연결 복구만으로 시작하지 않습니다. 시작 전 슬라이더는 잠깁니다.
Space는 정지 키입니다. Space를 놓아도 다시 시작하지 않습니다.
화면이 표시되고 연결이 정상인 동안 STOP까지 계속됩니다.

탭 숨김·페이지 종료·통신 끊김 시에는 명령 갱신을 멈추고 세션을 닫습니다.
다시 화면으로 돌아와도 자동으로 재시작하지 않습니다.

속도와 조향 표시의 의미
  속도 목표: 0~1850 ERPM. 모터의 전기 회전수이며 m/s가 아닙니다.
  조향각 입력: 현재 설정-0.550~+0.550 rad. 실제 바퀴 각도는 아직 보정되지 않았습니다.
  0.500: 직진 중립 후보이며 직진 실측값이 아닙니다.
  환산된 서보 목표: rad 입력을 서보0.3625~0.6375 범위에 임시 환산한 값.
  입력-0.55 rad → 서보0.3625 / 입력0 → 서보0.5 / 입력+0.55 rad → 서보0.6375.
  GUI는 제어기가 알려준 범위를 표시하고 사용합니다.
  기존0.25서보값/rad 비율을 유지하므로 입력±0.4는 이전처럼 서보0.4/0.6입니다.
  입력±0.5도 기존 서보0.375/0.625와 같습니다.
  화면의 ±31.5°는 입력 rad를 도로 환산한 표시이며 실측각이 아닙니다.
  현재 ±0.55 rad 입력이 실제 바퀴 ±31.5° 도달을 보장하지 않습니다.
  제어기 서보 명령: 변화율 제한을 거쳐 제어기가 보낸 값/최초 후보 가정.
  제어기 서보 명령은 서보의 실제 위치를 읽은 센서값이 아닙니다.
  음수/양수 입력의 실제 좌우 방향은 차량을 보면서 확인해야 합니다.

반응 속도
  슬라이더 변경은 최신 목표 하나로 합쳐 최대20Hz(50ms 간격)로 전송합니다.
  한 UPDATE 응답을 기다리는 동안 다음 목표를 중복 전송하지 않습니다.
  STOP은 UPDATE 제한/응답 대기열을 거치지 않고 별도 세션 종료 요청으로 즉시 전송합니다.
  다시 시작하려면 전역 STOP 응답과 그 이후에 시작한 조회의 최신 정지 상태를 확인해야 합니다.
  반복 STOP은 응답 대기 중인 전역 요청 하나로 합쳐 오래된 STOP이 새 세션을 끊지 않게 합니다.
  정지 응답 실패·거절 시 시작 잠금을 유지합니다. STOP을 다시 눌러 확인하세요.
  값이 바뀌지 않아도50ms마다 갱신을 준비하며 응답 대기 중에는 최신 목표 하나로 합칩니다.
  상태 조회는 HTTP 응답 시간을 포함한100ms 주기이며 동시에 중복 조회하지 않습니다.
  제어기는50Hz, 상태 발행은10Hz입니다. 통신 지연이 감시 한계를 넘으면 계속 해제합니다.
  GUI는 고정 DOM 참조를 재사용하고 준비 체크 항목이 바뀔 때만 목록을 다시 만듭니다.
  연속 수동 제어의 서보 명령 변화율은 최대0.40/s입니다.
  명령값0.3625→0.6375 전체 이동에는 변화율 제한만 고려하면 약0.6875초가 필요합니다.
  이는 실제 바퀴가0.6875초 안에 특정 각도에 도달한다는 보장이 아닙니다.
  모터 증가 변화율은 최대1200 ERPM/s, 감소 변화율은 최대2400 ERPM/s입니다.
  '속도0'은 제어기가 목표0을 수신한 뒤 감속 램프 없이 정지 출력을 보냅니다.
  (2026-11-12부터 commissioning.yaml 설정값은 0A가 아니라 브레이크 20A 후 핸드브레이크 15A 유지입니다.)
  이 버튼은 조향 세션을 유지합니다. 전체 제어를 끝내려면 STOP을 사용합니다.

속도 PID와900 ERPM 설정
  기존 제어도 VESC 내부의 속도 PID를 사용했습니다. PC에서 별도 PID를 중첩하지 않습니다.
  이전 저장 설정 s_pid_min_erpm=900이 목표900 미만에서 정상 속도 제어를 제한했습니다.
  새 배포는 최소 설정50 ERPM을 후보로 사용하고, 실제 장치 재조회 확인 후에만 GUI를 준비합니다.
  화면의 '조회 확인한 펌웨어 최소 설정'은 speed_pid_min_erpm_verified=true일 때만 표시됩니다.
  설정값50은 실제 모터가 모든 저속 목표에서 부드럽게 회전한다는 측정 결과가 아닙니다.
  사용자 관찰상 공중 시험에서 목표 약550 ERPM부터 부드럽게 회전했습니다.
  이 관찰값은 펌웨어 최소 설정과 따로 표시하며 실제 주행 최저속도는 미보정입니다.
  0<목표<관찰값이면 '이 범위는 멈추거나 끊겨 회전할 수 있습니다.'를 표시합니다.
  관찰값이 없는 제어기는 '관찰값 없음'을 표시하며 기존 시작 조건을 유지합니다.
  GUI는 작은 양수 목표를550/900으로 자동 확대하거나 목표값에 오프셋을 더하지 않습니다.
  실제 PWM 스위칭과 속도 PID는 VESC가 수행하며, C++는 목표·변화율·감시·정지를 담당합니다.

기존3초 시험과의 차이
  GUI는 axis=3(MANUAL), duration_s=0의 명시적 연속 세션을 사용합니다.
  axis=1(MOTOR), axis=2(STEERING)의 분리된 최대3초 시험은 C++ 서비스에 남아 있습니다.
  그 기존 시험의 서보 변화율은0.04/s입니다. 연속 제어 변화율과 구분합니다.
  GUI가3초마다 자동으로 재시작하는 방식은 아닙니다.

정지와 제한
  현재 공중 Wi-Fi 연속 MANUAL 후보는 마지막 명령 발행 시각 기준 통신 만료2초를 감시합니다.
  지연 명령의 나이를 잔여 시간에서 차감하므로 수신할 때마다 새2초를 주지 않습니다.
  최대 명령 나이·브라우저 상태 유효기간은 각각1.5초, HTTP 응답 제한은1500ms입니다.
  기본 설정과 MOTOR/STEERING 단기 시험의 통신 만료는0.35초 이하입니다.
  Pi 내부 telemetry 만료0.30초, 제어 타이머 정체0.20초는 유지합니다.
  새 세션은 최신 telemetry, 정지 유지, 단독 드라이버, 준비/timeout 확인이 필요합니다.

  서보에는 정지 시 새 위치를 보내지 않으므로 마지막 명령을 유지하며 자동 중립 복귀하지 않습니다.
  서보가 움직이지 못하면서 계속 힘주거나 이상음이 지속되면 전원을 끄고 기구를 확인하세요.
  최초 서보 후보는 실측 자세가 아니므로 첫 시작 때 조향이 움직일 수 있습니다.
