NOMAD 조향 명령 전달 진단 — 2026-11-06

결론
GUI→C++ 제어기→ROS→VESC 드라이버→USB 직렬 포트까지 조향 명령이 정상 전송됐습니다.
사용자는 실제 조향이 '조금 움직였음'이라고 확인했습니다. 각도 센서는 없어 실제 각도는 미측정입니다.

수정
사용자의 확대 요청에 따라 commission 설정과 드라이버 범위를0.49~0.51에서0.45~0.55로 확대.
RawOptions 기본값은0.49~0.51 유지, 명시 설정의 외곽 한도만0.45~0.55까지 허용.
변화율0.02/s, 최대3초, heartbeat/telemetry 만료, 단독 드라이버 조건, 축 분리 유지.
펌웨어 설정·전류 제한·속도 환산·조향각 보정값은 변경하지 않았습니다.

실제 시험
GUI: 조향만 / 서보0.550 / 3초, 실행 버튼을3초간 누름.
제어기 로그: START accepted axis=STEERING servo=0.5500 duration=3.00s.
ROS commands/servo/position:60개, 약0.500422→0.550.
드라이버 sensors/servo_position_command:60개, 동일한 값.
USB /dev/ttyACM0: COMM_SET_SERVO_POS(12) 패킷60개,0.500→0.550.
마지막 프레임:02 03 0c 02 26 57 a7 03. 전체8바이트 write 성공, CRC16 일치.
02 26은550이며 드라이버의1000배 인코딩에 따라0.550을 뜻합니다.
캡처한 actuator 패킷에 비영점 모터 명령 없음.
관찰 구간 telemetry1001개: 모터전류 절댓값 최대0A, fault0.
정지 중 ERPM 추정 잡음 절댓값 최대12가 관찰됐으며 실측 차속은 아닙니다.
진단용 strace는 종료했고 드라이버 TracerPid=0과 정상 telemetry 수신을 확인했습니다.

확인 범위와 한계
드라이버 echo는 명령의 재발행입니다. 물리적 서보 위치를 측정하지 않습니다.
USB write 성공은 호스트 전송 확인입니다. VESC5.03의 이 명령에는 별도 실행 완료 응답이 없습니다.
이번에는 사용자의 실제 움직임 관찰도 함께 있어 서보 반응까지 확인됐습니다.
서보0.55가 몇 도인지는 알 수 없으며 중립·끝단·선형 변환 보정은 별도 측정이 필요합니다.

작게 보일 수 있는 이유
기존 범위는 후보 중립에서±0.01이었고 여러 이전 실행은0.1~0.3초 만에 해제됐습니다.
변화율0.02/s 때문에0.1초 실행은 약0.002만 변합니다.
현재0.50→0.55는2.5초,0.45→0.55는5초가 필요합니다.
양 끝을 비교할 때는0.50을 거치는 별도3초 시험으로 나눠 직접 관찰하세요.
