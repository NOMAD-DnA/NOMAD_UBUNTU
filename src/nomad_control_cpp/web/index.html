차량 연결 확인 중

01수동 조작

조향만 조금씩 · 명령 자동 기록 · 모터 목표 0

정지 중에 설정합니다. 적용 후 한 단계 버튼으로 시험하세요.

실제 각도(°)가 아닌 서보 명령 범위입니다. 양쪽을 같은 폭으로 설정하며, 넓은 범위는 조향 전용 시험에만 사용합니다. 걸림·힘주는 소리가 생기면 즉시 STOP 후 범위를 줄이세요. 재시작하면 기본 범위로 돌아갑니다.

한 번에 최대 3초간 조향만 움직입니다. 종료 후 저장된 기록을 확인하세요. ± 버튼은 서보 명령의 증감이며 실제 좌우 방향은 바퀴를 보고 확인하세요. 현재 허용 범위 안에서만 움직입니다.

서보 명령 확인 중

조향 시험이 끝난 뒤 측정값을 입력하세요.

승인된 단계별 서보 요청을 Pi에 자동 기록합니다. 실제 바퀴 각도는 센서값이 없어 미측정으로 저장합니다.

차체 직진 방향을 0°로, 바퀴 방향이 왼쪽이면 + / 오른쪽이면 −로 입력하세요. 좌·우 바퀴는 차체 기준입니다. 입력 rad 눈금이 아니라 실제 측정한 각도입니다.

저장한 기록은 주행 보정에 자동 적용되지 않습니다.

  1. 수동 제어 시작을 누르면 속도 0으로 시작합니다.
  2. 속도와 조향 슬라이더로 조종합니다.
