NOMAD GUI · 2026-11-07 배포판
※ 11-07 배포판 기록입니다. 2026-11-12부터 속도 0·STOP은 제어기 설정에 따라 VESC 브레이크 후 핸드브레이크 유지일 수 있습니다(README '정지 출력').

사용하기
1. ZIP 전체를 원하는 폴더에 압축 해제합니다. 압축 파일 안에서 실행하지 마세요.
2. 바탕화면 바로가기 만들기.cmd를 실행합니다.
3. 처음 연결하는 PC는 연결 설정.cmd에서 Pi 주소, 계정, 작업 폴더를 입력합니다.
4. NOMAD GUI 시작.cmd를 실행합니다. Pi와 VESC가 켜져 있어야 합니다.
5. 브라우저에서 수동 제어 시작 → 속도/조향 슬라이더 → STOP 순서로 사용합니다.

조작
- 속도: ERPM. 시작은 항상 0이며 기존 1850 ERPM 상한을 유지합니다.
- 조향: 0~1 직접 입력. 0.0 / 0.5 / 1.0 버튼으로도 선택합니다.
- 속도 0: 모터 출력만 해제하고 조향 조작을 계속합니다.
- STOP, Esc, Space: 전체 수동 세션을 끝내고 모터 출력을 해제합니다.
- STOP은 브레이크가 아닙니다. 서보는 마지막 명령을 유지합니다.
- 연결 복구 후에는 수동 제어 시작을 다시 누릅니다.
- 상세 진단과 설정 상태는 '연결 및 제어 설정'을 펼쳐 확인합니다.

Pi 없이 보기
- NOMAD GUI 미리보기.cmd 또는 바탕화면 NOMAD GUI 미리보기를 실행합니다.
- 주소: http://127.0.0.1:8766/
- 화면과 슬라이더를 확인할 수 있으며, 실제 제어 START는 비활성입니다.
- 미리보기 EXE에는 ROS나 차량 출력 코드가 포함되어 있지 않습니다.

다른 PC에서 연결
- Windows 10/11 x64, OpenSSH 클라이언트와 최신 Chrome/Edge를 사용합니다.
- 이 배포판은 이미 NOMAD 제어기가 설치된 Pi에 연결하는 Windows 클라이언트입니다.
- Pi 작업 폴더에는 commission_session/ensure_gui.sh와 기존 VESC 서비스가 필요합니다.
- 동일 차량에 조종자는 한 명만 연결합니다. 세션 소유권은 제어기가 관리합니다.
- 비밀번호 로그인은 별도 SSH 창에 입력합니다. 그 창은 연결 중 열어 둡니다.
- SSH 키 로그인은 각 사용자가 이미 Pi에 등록한 본인 키를 지정합니다.
- 키 로그인은 known_hosts의 등록된 호스트를 검증합니다. 첫 접속은 일반 SSH에서 호스트를 확인해야 합니다.
- 개인 키, 비밀번호, connection.json, 주행/보정 기록은 배포 ZIP에 포함하지 않았습니다.
- 실제 연결 주소는 http://127.0.0.1:8765/ 입니다. 인터넷 공개 서버가 아닙니다.

이 버전의 변경
- 조향 0~1 유지. 사용자 보고: 2026-11-07 지상 시험에서 전 범위 정상 동작.
- 공중 시험, 중립 후보, 단위 설명 등 반복 문구 제거.
- 주요 화면은 시작/속도/조향/STOP과 ERPM/전압/전류로 구성.
- m/s와 km/h는 기존 영상 환산 비율을 유지하고 숫자 옆에 '추정'으로 구분.
- DOM 텍스트와 min/max 속성은 바뀔 때만 갱신. 최초 조향 소수점 표시 수정.
- VESC PID, 가감속 제한, 서보 변화율, STOP/통신 감시 한계는 유지.
- GUI 서버의 유휴 2ms 폴링 제거, 상태 잠금 구간 축소, 기록 경로의 계정 의존성 제거.
- Windows 실행기는 한 SSH 연결에서 Pi 서비스 준비와 GUI 터널을 처리.
- 조종 준비 시 공중 고정 여부를 반복해서 묻지 않으며, 실제 구동은 GUI START로 시작.

검증 및 Pi 반영
- Windows Release 빌드 및 로컬 CTest 10개 통과.
- 가짜 DOM/HTTP에서 연속 조작, STOP, 통신 지연, 직접 서보 명령 확인.
- Windows PowerShell 구문/설정 검사 및 실제 브라우저 미리보기 확인.
- 2026-11-07 Pi Release 빌드와 핵심/ROS 연동 테스트 4개를 모두 통과했습니다.
- 기존 Pi 실행 프로그램을 교체했고 실제 VESC telemetry와 바탕화면 연결/재연결을 확인했습니다. 실제 구동 START는 사용자가 누릅니다.
- 이 패키지는 새 Raspberry Pi 운영체제/ROS/VESC를 자동 설치하는 이미지가 아닙니다.

연결 문제
- Pi가 응답하지 않음: Pi 전원과 같은 네트워크 연결을 확인합니다.
- 8765 포트 사용 중: 이전 SSH 터널 창을 닫고 다시 실행합니다.
- Permission denied: Pi 계정 또는 SSH 키/비밀번호를 확인합니다.
- VESC 데이터 대기: VESC 전원과 USB 연결을 확인합니다.
- 로그: Windows 사용자 LocalAppData/NOMAD-Control 폴더
