NOMAD 조향 명령 자동 기록 / 선택 실측 모드 (2026-11-07)

현재 소프트웨어가 아는 값과 모르는 값
- 알 수 있음: 요청한 서보값, 제어기 요청 승인, 최신 제어기 명령값, 요청 시각.
- 알 수 없음: 실제 서보 축 위치, 앞바퀴 각도, 기계적 최대 조향각.
- 현재 연결 코드와 VESC telemetry에 앞바퀴 각도 피드백 경로가 없습니다.
- 서보 요청 0.005의 증가가 바퀴 몇 도에 해당하는지는 명령만으로 측정할 수 없습니다.
- 자동 명령 기록은 각도 측정이 아닙니다. 실제 각도 자동 취득에는 각도 센서 또는 보정된 영상 측정이 필요합니다.

사용 방법
1. 모든 바퀴를 띄워 고정하고 NOMAD GUI 시작에서 2번 공중 조종 준비를 선택합니다.
2. 일반 조종 중이면 STOP으로 끝낸 뒤 '조향각 보정 모드 열기'를 누릅니다.
3. 한 단계 서보 변화량을 선택합니다. 기본 0.005, 미세 0.0025, 큰 단계 0.01.
4. - 한 단계 / + 한 단계를 누르면 STEERING 축의 짧은 시험이 시작됩니다.
   모터 목표는 항상 0이며 일반 속도·조향 슬라이더는 잠깁니다.
   최대 3초 후 시험이 끝납니다. STOP/Esc는 즉시 종료 요청입니다.
   Wi-Fi 지연으로 짧은 시험이 중단되면 새 상태를 확인하고 다시 한 단계를 요청합니다.
5. 승인된 서보 요청은 Pi에서 자동 기록합니다. 각도 입력이나 저장 버튼 조작이 필요 없습니다.
   같은 시험에서 같은 목표를 유지하는 heartbeat는 중복 저장하지 않습니다.
   거절된 요청은 승인된 명령 기록으로 남기지 않습니다.
6. 시험이 끝난 뒤 '저장된 명령·측정 기록 보기'를 펼칩니다. 필요하면 기록 새로고침을 누릅니다.
7. 눈으로 본 반응을 남기고 싶다면 정지 후 메모에 '부드러움', '움직임 안 보임' 등을 적고
   '현재 명령에 메모 저장'을 누릅니다. 각도는 몰라도 됩니다.
8. 실제 각도를 알게 된 경우에만 '실측각을 알고 있는 경우에만 각도 추가 입력'을 체크합니다.
   차체 직진 기준 0도, 바퀴 방향이 왼쪽이면 양수/오른쪽이면 음수로 양쪽 바퀴를 기록하고
   직접 측정 확인 체크 후 '실측각과 메모 저장'을 누릅니다.
   GUI rad 눈금이나 임시환산 각도를 실측각으로 복사하지 않습니다.

저장 내용
- Pi 경로: /home/user/nomad_cpp_ws/calibration/steering/<기록ID>.json
- kind=command: 자동 기록. servo_command는 승인된 요청 목표값입니다.
  observed_servo_command는 승인 시점 부근에서 받은 최신 제어기 명령 상태입니다.
  제어기 상태는 주기적으로 갱신되므로 목표 도달 여부를 뜻하지 않습니다.
- kind=observation: 사용자가 메모를 남길 때 최신 제어기 명령과 함께 저장한 기록입니다.
- 위 두 기록의 각도는 null, measured_confirmed=false입니다. 0도라고 가정하지 않습니다.
- kind=measured: 사용자가 직접 입력하고 확인한 실측각(deg/rad)입니다. 센서값이 아닙니다.
- 저장 시각, 종류, 서보값, 실제 각도의 미측정 여부를 구분해 표시합니다.
- applied=false: 주행용 보정계수와 최대 조향 범위를 자동 변경하지 않습니다.
- 같은 요청을 다시 보내도 중복 저장하지 않습니다. 원본은 덮어쓰지 않습니다.
- 잘못 기록했다면 메모에 정정임을 적고 새 기록으로 남깁니다. 최종 보정표 생성 때 검토해야 합니다.
- 최근 25개를 화면에 표시하며 전체 원본 최대 1000개를 파일로 보관합니다.

제한과 확인
- 일반 주행 범위는 0.3625~0.6375. 조향 전용 시험은 아래 슬라이더로 별도 조절합니다.
- 조향 전용 축은 C++ 제어기에서 비영점 모터 목표를 거부합니다.
- 메모와 실측 저장은 연결/telemetry/정지 상태/모터 명령0/서보값 일치/입력 범위를 검증합니다.
- 자동 요청 기록은 조향 전용 시험의 모터0 요청이 제어기에 승인된 경우만 남깁니다.
- 저장 오류는 화면의 자동 기록 상태에 표시합니다. 오류가 있으면 기록 성공으로 간주하지 마세요.
- 이동 명령이 바뀌면 기존 실측 확인을 취소합니다. 움직이는 동안 측정 도구나 손을 대지 않습니다.
- 실제 바퀴 각도 센서가 없으므로 조향 정지는 사용자가 직접 확인해야 합니다.
- 공중 측정값은 탑재 하중을 받은 지상 상태와 다를 수 있습니다. 경사 주행 허용을 뜻하지 않습니다.

코드
web/index.html: calibrationStep, targets, refreshCalibration, saveCalibration, loadCalibration.
src/gui_server.cpp: steeringRecords는 메모/실측 검증, recordSteeringCommand는 승인 요청 자동 기록.
include/nomad_control_cpp/steering_records.hpp: 저장/조회/중복 및 입력 검증.

조향 시험 최대 범위 슬라이더
- 보정 모드 상단의 '조향 시험 최대 범위' 슬라이더는 중립 0.5로부터의 양쪽 변화량입니다.
- 기본 0.1375 → 서보 0.3625~0.6375. 예: 0.15 → 0.35~0.65.
- 설정 가능한 변화량은 0.005~0.5, 눈금은 0.0025입니다. 최대 설정은 명령 0~1입니다.
- 이 숫자는 실제 각도나 PWM 듀티 비율이 아닙니다. 실제 기계적 한계는 아직 모릅니다.
- 슬라이더를 움직인 후 '범위만 적용 · 움직이지 않음'을 누릅니다. 이 동작은 START/UPDATE를 보내지 않습니다.
- 화면 '현재 서보 명령' 옆의 적용 범위를 확인한 뒤 ± 한 단계 버튼으로 조금씩 시험합니다.
- 넓은 범위를 한 번에 적용해도 바퀴가 끝으로 움직이지 않습니다. 단계 버튼은 기존 변화량과 느린 조향 속도를 유지합니다.
- 범위 변경은 최신 telemetry에서 모터가 정지한 상태만 허용합니다. 시험 중에는 변경할 수 없습니다.
- 현재 서보 명령보다 안쪽으로 범위를 줄이면 거부합니다. 먼저 단계 버튼으로 안쪽에 복귀한 뒤 줄입니다.
- 통신 보호 정지(FAULT) 후에는 범위 적용 버튼이 정지 재준비를 거칩니다. 구동은 하지 않습니다.
- 넓힌 범위는 모터0의 조향 전용 축에만 적용됩니다. 일반 속도/조향 MANUAL 범위는 확대하지 않습니다.
- 현재 서보 명령이 일반 범위 밖에 있으면 일반 모터 구동을 막습니다. 조향 전용 단계 버튼으로 복귀해야 합니다.
- 제어기 재시작 시 기본 범위로 돌아갑니다. 기록 파일은 유지되지만 시험 한계를 자동 영구 적용하지 않습니다.
- 걸림이나 힘주는 소리가 발생하면 STOP하고, 더 크게 밀지 말고 반대 방향으로 조금 돌아온 뒤 한계를 낮추세요.
- 드라이버 config/vesc_steering_test.yaml은 0~1 전달을 허용합니다. 축별 실제 허용 범위는 C++ RawTrialController가 검사합니다.
