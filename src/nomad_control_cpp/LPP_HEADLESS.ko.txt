GUI 없이 LPP 토픽으로 제어 — 2026-11-09

이 변경으로 GUI 시작 버튼과 GUI heartbeat 없이 LPP 명령만으로 출력할 수 있습니다.
전용 프로필을 사용하지 않는 기존 GUI 수동/자동 모드는 기존 동작을 유지합니다.
운영 Pi에 이 모드를 자동으로 실행하거나 차량에 시험 명령을 보내지는 않았습니다.

1. 소스 교체 후 NOMAD_ENABLE_PLANNING=ON으로 다시 빌드하고 install/setup.bash를 source합니다.
   colcon build --packages-up-to nomad_control_cpp --cmake-args -DNOMAD_ENABLE_PLANNING=ON -DCMAKE_BUILD_TYPE=Release
   source install/setup.bash
2. 기존 controller_node 통합 launch의 parameters 목록에 아래 파일을 순서대로 지정합니다.
   config/commissioning.yaml
   config/planning.yaml
   config/planning_headless.yaml  (반드시 마지막)
   기존 실제 VESC 준비 확인 값 commissioning_setup_acknowledged,
   hardware_timeout_verified, speed_pid_min_erpm_verified는 유지합니다.
   기본 commissioning.yaml만 사용하면 이 준비 값들은 false여서 출력되지 않습니다.
3. 같은 드라이버를 사용하는 기존 controller_node는 종료하고 하나만 실행합니다.
   GUI는 켜지 않아도 됩니다. 전용 모드에서는 수동 명령이 출력 권한을 빼앗지 못합니다.
   수동 GUI를 다시 쓸 때는 headless 프로필 없이 기존 실행 방식으로 돌아갑니다.
4. LPP가 다른 장치라면 ROS_DOMAIN_ID를 일치시키고 ROS_LOCALHOST_ONLY=0으로 설정합니다.
   두 장치에서 /nomad/planning/drive_command의 publisher가 정확히 하나인지 확인합니다.

명령 계약:
/nomad/planning/drive_command, nomad_interfaces/msg/DriveCommand
header.frame_id=base_link, header.stamp=현재 ROS 시각, valid_for=0.3초(최대0.5초).
target_speed: 0~0.25 m/s, target_steering_angle: -0.3~+0.3 rad, stop_requested=false.
권장20~50Hz. 예: 0.2 m/s는 약744 ERPM. 범위 밖 명령은 제한값으로 잘라 쓰지 않고 거부합니다.
정상 telemetry/드라이버/준비 조건 및 유효 LPP 명령이 갖춰지면 GUI 없이 시작합니다.

정지/재개:
LPP stop_requested=true 또는 /nomad_vesc_trial/stop (std_srvs/srv/Trigger)으로 정지합니다.
LPP 명령 만료, telemetry/드라이버 이상에서도 정지합니다. 연결 복구만으로 재출발하지 않습니다.
정지 원인을 해결하고 차량이 멈춘 뒤 다음 명령으로 다시 준비합니다.
ros2 service call /nomad_vesc_trial/reset std_srvs/srv/Trigger '{}'
reset 성공 후 새로 들어오는 유효 LPP 명령으로 다시 시작합니다. 노드 namespace가 있으면 서비스 경로도 맞추세요.

초기 보정 실행:
planning_headless.yaml은 planning.headless=true와 planning.allow_estimated_calibration=true를 명시합니다.
기존 사진/영상 초기 보정표로 실행하도록 요청한 모드이며 calibration_verified를 true로 속여 바꾸지 않습니다.
실측 보정이 미완료이므로 speed_valid/steering_valid는 false일 수 있습니다. LPP가 이 값들을 필수로 기다리면 그 정책도 팀에서 확인해야 합니다.
실측 검증 값만 쓰려면 allow_estimated_calibration=false로 두세요. 검증되지 않은 값으로는 시작되지 않습니다.

상태 확인:
ros2 topic echo /nomad_vesc_trial/status_json --once
planning_headless=true, planning_ready, planning_reset_required, reason을 확인하세요.
이전 실행파일에는 새 파라미터가 없으므로 YAML만 복사하지 말고 새 소스로 빌드해야 합니다.
