NOMAD DRIVE LAB · 모의 주행 화면

실행: 바탕화면 NOMAD 모의 테스트 또는 desktop/Simulation.cmd.
수동: 마우스/키보드 선택 후 수동 제어 시작. W/S 속도, A/D 좌우 조향.
LPP: LPP 자율 제어 선택 후 시작. 예제 속도/각도 명령이 자동으로 변화함.
Esc/Space/STOP: 정지. 모드 변경 후에는 다시 시작.
정지하고 위치·궤적 초기화: 차량 위치/방향/이동 궤적을 원점으로 초기화.

기본 고정 화면: 격자는 그대로이고 차량이 화면 안에서 이동함.
상단 선택 상자에서 차량 따라가기로 바꾸면 차량 중심 주변으로 격자/궤적이 이동함.
주행 중 시점 전환은 차량 제어에 영향을 주지 않음. 고정으로 바꾸면 그때 시점을 유지함.
차량 위치로 화면 이동: 화면 밖의 차량을 다시 중앙에 표시. 이후에도 고정 시점 유지.
앞쪽 화살표는 차량 진행 방향, 뒤쪽 두 바퀴는 후륜 조향 모델에 따라 회전함.
GUI 조향 입력: 0=차량 진행 방향 기준 좌회전, 0.5=중앙, 1=우회전.
수동 raw 서보 명령=1-GUI 조향 입력. A/왼쪽 키는 좌회전 입력을 증가시킴.
모의 모델 가정: 1000 ERPM=1m/s, 서보0.5 직진, 등가각=(servo-0.5)*1.4 rad,
축간거리0.335m. 이 환산과 부호는 모의 모드 전용이며 실차 보정에 사용하지 않음.
평면 운동학 예시이며 노면/마찰/슬립/제동거리/충돌과 실제 LPP 경로 계획은 재현하지 않음.

검증: Windows Qt 40개 검사 통과. 직진 거리, 좌우 대칭 궤적,
모의 LPP 이동, STOP 후 위치 정지 포함. 실제 Windows 화면 렌더 확인.
