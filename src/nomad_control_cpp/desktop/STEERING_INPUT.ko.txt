Qt GUI 조향 입력 방향 변경 · 2026-11-08

GUI 0 = 좌회전 입력 / 0.5 = 중앙 입력 / 1 = 우회전 입력.
실제 CommissioningControl servo_position = 1 - GUI 입력.
즉 GUI 0/0.5/1 → raw 서보 1/0.5/0.
화면 숫자는 이제 raw 서보 명령이 아닌 조향 입력값임.
시작 시 마지막 raw 명령을 역변환하여 표시하므로 시작만으로 목표가 뒤집히지 않음.
A/왼쪽 키: GUI 입력 감소 → raw 서보 증가 → 좌회전 의도.
D/오른쪽 키: GUI 입력 증가 → raw 서보 감소 → 우회전 의도.

모의 차량도 동일 입력 방향으로 맞춰 검사함.
실차 방향은 사용자 관찰을 바탕으로 변환했으며 Pi/VESC에서는 아직 재확인하지 않음.
LPP rad 계약과 실제 제어기의 planning.yaml 보정값은 변경하지 않음.
기존 웹 GUI는 raw 서보값 입력이므로 이 Qt 입력값과 구분할 것.
