  cd C:\Users\user\Documents\ChatGPT\NOMAD\nomad_control_cpp
  ssh -F .\config\pi4_monitor_ssh.conf nomad-pi4-monitor "bash /home/user/nomad_cpp_ws/monitor_session/start.sh"
Pi 계정 비밀번호를 직접 입력합니다. start.sh는 MONITOR만 실행하며 같은 작업의 중복 실행을 막습니다.

현재 자동 연결이 끊긴 뒤 GUI 터널을 다시 열 때:
  ssh -F .\config\pi4_monitor_ssh.conf -N -o ExitOnForwardFailure=yes -L 127.0.0.1:8765:127.0.0.1:8765 nomad-pi4-monitor
로그인한 PowerShell 창을 계속 열어 두고 브라우저 http://127.0.0.1:8765 를 새로 고칩니다.
현재 터널이 살아 있으면 8765 포트가 이미 사용 중이므로 두 번째 터널을 실행하지 마세요.
이 명령으로 직접 연 터널은 Ctrl+C로 종료합니다.
IPv6 link-local 주소는 같은 네트워크에서만 사용할 수 있습니다. Wi-Fi 인터페이스 번호가 바뀌면
Get-NetIPInterface -AddressFamily IPv6로 번호를 확인하고 SSH 설정의 %%20을 새 번호로 바꿉니다.

이번에 실행한 Pi 수신 프로세스만 종료:
  ssh -F .\config\pi4_monitor_ssh.conf nomad-pi4-monitor "bash /home/user/nomad_cpp_ws/monitor_session/stop.sh"
이 스크립트는 기록된 PID와 실행 파일을 대조해 이번 GUI/제어기/드라이버만 종료합니다.
브라우저 창만 닫는 것은 Pi 프로세스 종료가 아닙니다.
Pi 재부팅 후 자동 실행은 설정하지 않았습니다. 필요하면 start.sh로 다시 시작합니다.

배포에 쓴 임시 SSH 키는 작업 종료 시 제거합니다. 유지 중인 터널은 그대로 동작하지만,
