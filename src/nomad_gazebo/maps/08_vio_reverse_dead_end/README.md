# 바위 계곡 · 후진 복귀

바위 막다른 길에서 후진 후 북측 고도 샛길로 우회하여 뒤편 목표점 (34, 0)에 도달하는 시험 환경.

- 기준 경로: 51.0m. `route.csv`는 계획 경로이며 실제 GT는 `/odom`.
- 23m 지점까지 전진 후 회전 없이 같은 길로 후진 복귀, 총 약 102m.
- 출발: (-28, 0). 도로 폭 3m.
- `map_preview.png`: 계획 경로와 물체 배치. Gazebo 화면 캡처 아님.
- 기존 차량·센서·구동 설정 유지. 맵 생성·로딩 확인과 알고리즘 주행 성공은 별개.

- 우회 시험: 막힌 지점 (23, 0) → 후진하여 분기 (-14, 0) → 북측 샛길 → 목표 (34, 0).
- `bypass.csv`: 높이 약 3.2m의 우회 계획 경로. 자동 경로 선택·후진 제어는 기존 자율주행 모듈에서 수행.
