NOMAD Windows 관전 설치 (Windows 10/11 x64)

공유폴더의 NOMAD_Windows_Demo_Setup.cmd를 더블클릭합니다.
NOMAD_Windows_Spectator_Setup.cmd도 동일한 설치 파일입니다.
파일 하나만 PC에 복사해서 실행해도 됩니다. 관리자 실행은 필요 없습니다.
처음 설치할 때 인터넷 연결이 필요합니다. Python 3.12가 없으면 winget으로 설치합니다.
winget이 없으면 python.org에서 Python 3.12 x64를 설치한 뒤 다시 실행합니다.
설치 실패 메시지가 나오면 해당 메시지를 확인해 주세요. 회사 정책으로 스크립트 실행이 차단되면 관리자에게 문의합니다.

시연용: 윈도우 PC를 우분투 운용 PC의 핫스팟에 연결하고 바탕화면의 NOMAD Demo를 실행합니다.
주소 입력 없이 demo.ini에 저장된 주소로 관전 창이 바로 열립니다. 초기값은 10.42.0.1:8768입니다.
설치 후 바탕화면의 NOMAD Demo Settings를 누르면 설정 파일이 메모장으로 열립니다.
아래 relay 값만 바꾸고 저장한 뒤 NOMAD Demo를 닫았다 다시 실행합니다.

[connection]
relay = 10.42.0.1:8768

설정 파일 경로: %LOCALAPPDATA%\NOMAD-Spectator\demo.ini
재설치나 업데이트를 해도 이미 저장된 설정 파일은 덮어쓰지 않습니다.
설정이 잘못되면 오류를 표시합니다. 다른 주소로 임의 연결하지 않습니다.
이 파일은 시연 바로가기 전용이며 NOMAD Spectator의 마지막 수동 입력 주소와 별개입니다.
운용 PC에서 화면 연결과 중계가 켜져 있어야 실제 시험 데이터가 표시됩니다.
운용 PC가 아직 준비되지 않았으면 관전 창을 열어 둔 채 자동으로 재연결합니다.
인터넷이나 공유폴더는 실행에 필요 없습니다. 핫스팟 Wi-Fi 연결은 먼저 해야 합니다.
운용 PC의 핫스팟 주소나 중계 포트를 바꾸면 demo.ini의 relay 값을 변경합니다.

수동 연결용: 바탕화면의 NOMAD Spectator를 실행합니다.
우분투 운용 PC에서 화면 연결과 중계를 켜고, 표시되는 주소:포트를 입력합니다.
기본 포트는 8768입니다. 공유폴더 서버 주소와 운용 PC 주소는 다를 수 있습니다.
같은 네트워크에서 운용 PC 중계 포트에 연결할 수 있어야 합니다.
연결이 안 되면 운용 PC의 중계 실행 상태, 주소, 방화벽, Wi-Fi 기기 간 통신 차단을 확인합니다.

관전은 영상, 지도, 궤적과 상태를 받는 읽기 전용입니다.
ROS 설치, 보드 비밀번호, SSH 접속은 필요 없습니다.
차량 제어, 시험 시작과 종료 및 설정 변경은 우분투 운용 PC에서 합니다.
중계는 기존 앱과 동일하며 로그인과 암호화가 없으므로 신뢰하는 내부망에서 사용합니다.

설치는 %LOCALAPPDATA%\NOMAD-Spectator 아래에 저장합니다.
설치 후 공유폴더 연결이 끊겨도 실행할 수 있습니다.
업데이트는 새 Setup.cmd를 다시 실행합니다. 우분투 GUI의 자동 업데이트와 별개입니다.
삭제는 앱을 닫고 위 폴더 및 바탕화면과 시작 메뉴의 NOMAD Spectator, NOMAD Demo, NOMAD Demo Settings 바로가기를 삭제합니다.
Python 자체는 다른 프로그램이 쓸 수 있으므로 자동 삭제하지 않습니다.

2026-11-25: 리눅스에서 관전 창, 가상 TCP 중계, 개발 창, 시연 무입력 연결과 수동 연결 보존 검사를 통과했습니다.
기존 중계 검사 6개도 통과했습니다.
PowerShell 구문과 자체 압축 해제를 확인했고 Windows x64 의존성 패키지를 내려받아 확인했습니다.
실제 Windows 설치, 바탕화면 등록과 Ubuntu-Windows 연결은 미검증입니다.

우분투 원본의 Fusion 스타일과 Ubuntu Sans 11pt 및 한국어 Noto Sans CJK 글꼴을 앱에 포함합니다.

창 크기와 화면 배율이 같을 때 비교하세요. 윈도우 제목 표시줄과 글자 렌더링은 OS에 따라 차이가 남을 수 있습니다.

관전 버튼은 계속 비활성이고 플래너 시작, 종료나 차량 제어 명령을 보내지 않습니다.

운용 PC도 공유폴더 원본 업데이트를 적용한 GUI로 다시 열어야 합니다.
보드 센서나 플래너 실행 파일은 이 변경으로 수정하지 않습니다.
